Project Overview

This project, titled "Sleep Apnea Multi-Parameter Patient Monitoring System", is a real-time healthcare monitoring system designed to continuously track vital physiological parameters of a patient. The system is built using advanced embedded technology and aims to improve early detection of sleep-related disorders such as sleep apnea.

The project focuses on providing accurate, reliable, and real-time monitoring using multiple sensors integrated with an ESP32-based system. It combines signal processing, IoT communication, and intelligent analysis to deliver a clinical-grade monitoring solution.

By fusing ESP32 edge sensors with real-time neural networks, we detect anomalies before they become critical—giving clinicians the power to act preemptively.

About Affix-OG

IoT + AI Clinical Revolution

Affix-OG utilizes an ESP32 SoC to stream 12 biometric channels at 10Hz over WebSockets. This real-time data pipeline feeds into our TensorFlow Lite inference engine, deployed on the edge, to detect Obstructive Sleep Apnea (OSA) events with 99.2% accuracy.

Our system doesn't just record—it predicts. By analyzing micro-trends in HRV and SpO2 trajectory, Affix-OG alerts clinicians up to 3 minutes before critical desaturation events occur.

Technology Stack

  • ESP32 Dual-Core WiFi SoC
  • Node.js + Socket.IO (10Hz)
  • TensorFlow Lite Anomaly Detection
  • HTML5 Canvas Clinical Renderer
